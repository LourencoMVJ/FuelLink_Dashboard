Inter-company Offset Dashboard

Bakers hauls diesel for Fuel Link's routes; Fuel Link sells diesel to Bakers. This nets the two flows into one running balance, shared live between both parties.

Sign in

Each party signs in with their own account. Once signed in, the database only accepts your own side's transactions — that's enforced by the server, not just the page, so the other party genuinely cannot post or alter your entries. Entries are append-only: corrections are made by adding a Void, which stays visible in the ledger. Both parties see the same live data from their own computer.

Entries are append-only for all financial fields: the database has no update or delete permission for date, type, amount, litres, etc. To correct a mistake, void it — that adds a reversing entry and keeps the original visible for the audit trail. You can only void entries your own party entered. The truck, driver and trailer on an entry can be edited by either party — useful for filling in that detail on entries recorded before this was tracked.
