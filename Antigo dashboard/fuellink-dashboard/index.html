Fuel Link / Rwendo Services Bakers Tankers (Pty) Ltd

Inter-company Offset Dashboard

Bakers hauls diesel for Fuel Link's routes; Fuel Link sells diesel to Bakers. This nets the two flows into one running balance, shared live between both parties.

Sign in

Each party signs in with their own account. Once signed in, the database only accepts your own side's transactions — that's enforced by the server, not just the page, so the other party genuinely cannot post, edit or void your entries. You can correct your own entries directly with Edit, or reverse one with Void, which stays visible in the ledger. Both parties see the same live data from their own computer.
